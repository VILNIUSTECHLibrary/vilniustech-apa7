# VILNIUS TECH – APA 7th edition for LaTeX

A VILNIUS TECH LaTeX wrapper for using the APA 7th edition citation and reference style through the external `biblatex-apa` package.

This project provides a simple LaTeX entry point for loading the APA style implemented by `biblatex-apa`.

This project is not affiliated with, endorsed by, sponsored by, or otherwise approved by the American Psychological Association (APA).

## Design

This package is intentionally a thin wrapper around the external `biblatex-apa` implementation.

Architecture:

`VILNIUS TECH LaTeX wrapper` → `biblatex-apa` → `APA 7 style`

The wrapper does not implement its own APA citation or bibliography rules.

It does not copy, fork, or modify the implementation of `biblatex-apa`.

The wrapper does not include the `biblatex-apa` style files such as `.bbx`, `.cbx`, `.dbx`, or `.lbx`.

## What the package provides

Loading `vilniustech-apa7` provides:

* `csquotes`;
* `biblatex` with the `apa` style;
* the Biber backend.

The actual APA citation and bibliography formatting is provided by the installed `biblatex-apa` package.

This package does not pin a particular version of `biblatex-apa`. The version available in the user's LaTeX distribution is used.

## Requirements

The package requires:

* LaTeX;
* `biblatex`;
* `biblatex-apa`;
* `csquotes`;
* Biber.

Please refer to the current `biblatex-apa` documentation for its dependency requirements and supported environments.

## Basic use

```latex
\documentclass{article}

\usepackage[american]{babel}
\usepackage{vilniustech-apa7}

\addbibresource{references.bib}

\begin{document}

A parenthetical citation \parencite{example}.

A narrative citation \textcite{example}.

\printbibliography

\end{document}
```

Compile the document with LaTeX and Biber. For example:

```text
pdflatex main
biber main
pdflatex main
pdflatex main
```

On Overleaf, use Biber as the bibliography processor when necessary.

## Options

Options passed to `vilniustech-apa7` are passed through to `biblatex`.

For example:

```latex
\usepackage[sorting=nyt]{vilniustech-apa7}
```

The wrapper is intended specifically for the `apa` style and the Biber backend.

## Languages

Language selection is handled using the normal LaTeX mechanisms such as `babel` or `polyglossia`.

The wrapper does not replace or modify the localization files provided by `biblatex-apa`.

For example:

```latex
\usepackage[english]{babel}
\usepackage{vilniustech-apa7}
```

## Compatibility

The package is intended to work in LaTeX environments where the required dependencies are available, including:

* TeX Live;
* MiKTeX;
* Overleaf;
* Windows;
* macOS;
* Linux.

Compatibility ultimately depends on the versions of LaTeX, `biblatex`, `biblatex-apa`, `csquotes`, and Biber available in the user's environment.
